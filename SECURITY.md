# Security policy

## Sensitive data

Never include Douyin cookies, browser profiles, signed media URLs, `config.yml`, downloaded media, model caches, SQLite state, or generated personal notes in an issue or pull request.

The repository audit rejects common secret-bearing filenames, media/database artifacts, personal Windows paths, and several credential patterns. This check reduces accidental disclosure but does not replace a manual review.

## Reporting a vulnerability

Please report security problems privately through GitHub Security Advisories when available. Include the affected version, reproduction steps, and impact. Do not include real account credentials or private video URLs.
